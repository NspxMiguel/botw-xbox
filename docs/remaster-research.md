The realistic near-term addition is a small, separately downloaded Wii U UI/texture
replacement after licence and memory verification. Broad HD textures and temporal
AO/GI are poor defaults with only ~565 MiB of original headroom. Keep the compiled
Remaster baseline as the release candidate and validate its existing clarity,
shadows/reflections/distance before adding another renderer stack.

The existing store queries GameBanana game 5866, downloads from author-provided
URLs, installs file replacements under `LocalState/mods`, and locks imported
graphics packs pending recompilation. It neither supplies BCML/UKMM merging nor
executes downloaded PPC patches or ReShade effects. A GameBanana listing therefore
means a player can obtain a file, not that its licence, archive layout, dependency
closure or compatibility has been certified. See `runtime/src/mods/README.md`.

For any future candidate, record the exact author/file version, readable licence,
Wii U format, dependencies and console high-water memory at the chosen output and
internal scale. Prefer direct author links over mirrors. These are release checks
for a proposed addition; this research does not authorize bundling any assets.
