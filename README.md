# cafe-uwp

Experimental UWP / Direct3D 12 host for statically recompiled PowerPC (Cafe OS) code, aimed at
Xbox Series consoles in Developer Mode. Work in progress; nothing here is ready for players.

No game files, keys or other copyrighted assets are included. Building requires your own legally
obtained files.

## Build

See `docs/CI.md` and `.github/workflows/` for the macOS and UWP builds.
